# Mind Bites 🧠✨

Automated daily visual knowledge, infographics, and quick brain food publisher for Instagram (`@mind.bites3`) and Facebook Page (`Mind Bites`).

## ⏰ Daily Posting Schedule (2X Daily)
- **Morning Peak Slot:** 11:30 AM IST (06:00 UTC)
- **Evening Prime Slot:** 08:30 PM IST (15:00 UTC)

## 🚀 Features
- 100% automated via GitHub Actions
- High-res images hosted on ultra-fast Catbox CDN
- Dynamic Hindi & Hinglish caption generation with viral hashtags
- Infinite circular cycle loop
